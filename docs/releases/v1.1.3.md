# Portafolio v1.1.3 — El portafolio deja de listarse a sí mismo

**Fecha:** 2026-11-08  
**Repositorio:** <https://github.com/wilkin-barban/Portafolio>  
**Sitio:** <https://wilkinbarban.duckdns.org>  
**Tipo:** parche de contenido (sin cambios funcionales)

## Qué cambió

El proyecto **Portafolio** ya no aparece como una tarjeta/caso de estudio dentro del propio portafolio. El repositorio sigue existiendo como sitio y respaldo, pero la sección de proyectos muestra únicamente los cinco proyectos de producto:

- CRM Sofia Manager
- Trindade Massas
- Super Chat Manager
- FF-Converter
- pi-auto-compaction

Se eliminaron:

- La entrada de Portafolio en `public/data/projects.json`.
- El objeto de Portafolio en `public/locales/es.json`, `en.json` y `pt.json`.
- La carpeta de capturas `public/Portafolio/`.
- La fila de Portafolio en el README y en el README del perfil de GitHub.
- El contador estático de 6 a 5 proyectos.

## Detalles técnicos

- `assetVersion` actualizado a `20261109-3`.
- `app.js`, `i18n.js` y el HTML usan `?v=20261109-3` para evitar datos y traducciones cacheadas.
- Express envía `Cache-Control: no-cache` para `.html` y `.json`; las imágenes siguen con caché normal.
- `/api/stats` reporta 5 proyectos; `/api/gallery/Portafolio` devuelve 404 porque ya no está autorizado.
- Se regeneró el OG/social preview con el hero actualizado de 5 proyectos.

## Calidad

```bash

```

- Suite local 24/24 tests OK (ahora exige 5 proyectos por idioma y 5 metadatos).
